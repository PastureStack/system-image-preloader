# PastureStack System Image Preloader v0.3.0

This is the first reviewed PastureStack release after the preserved upstream
`v0.2.2` boundary.

## Runtime changes

- Uses the neutral `system-image-preloader` command and image identity.
- Discovers infrastructure workload images through the compatibility metadata,
  environment, and catalog APIs.
- Supports both plain and templated Compose catalog payloads.
- Pulls only missing images and stops after a bounded number of failures.
- Uses Go 1.26.5 for source-built helper tools, builds Docker CLI from its
  verified release commit, updates fixed `gomplate` dependencies, and removes
  an unused vulnerable helper inherited from the Ubuntu base.
- Fixes the metadata host path so the default `/latest` base is not repeated.
- Resolves both absolute and relative catalog version links.
- Includes an isolated API-to-Docker cache lifecycle smoke test.

## Deployment

Use `ghcr.io/pasturestack/system-image-preloader:v0.3.0`.

The service requires the host Docker socket and therefore has host-equivalent
administrative access. Deploy it only as a trusted global, start-once
infrastructure service.
